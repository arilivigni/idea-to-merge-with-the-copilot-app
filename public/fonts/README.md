# Fonts

Self-hosted [Monaspace](https://github.com/githubnext/monaspace) webfonts (by GitHub Next),
used to theme **Mona's Bookmark Manager App**.

- `MonaspaceNeon-{400,600,700}.woff2` — body text
- `MonaspaceXenon-{600,700}.woff2` — headings

These `latin`-subset `.woff2` files were sourced from the
[Fontsource](https://fontsource.org) distribution of Monaspace. They are served
from the site root (`/fonts/...`) so the app renders its brand font offline, with
no runtime CDN dependency.
